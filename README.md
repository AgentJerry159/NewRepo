# 面部视频原始特征提取工具：零基础使用说明

这个工具会把视频中人脸的**原始面部特征**整理成 Excel，方便后续与皮温、HRV、眼动等数据一起做疲劳研究。

它不是“疲劳诊断器”：不会直接给某人判定疲劳、不会自动分三级疲劳，也不会给出医学或驾驶安全结论。这些结论必须在后续结合研究设计、外部数据和统计分析后再建立。

## 先看：这个软件能得到什么？

默认的“精简指标”会每秒均匀分析 12 张画面，并在每个视频的 Excel 中保存每个时间点的：

- 时间信息：视频内秒数、对应原始帧号，以及六段五分钟视频合并后的实验时间轴；
- 人脸是否被检测到，以及 `FaceScore` 人脸检测质量分数；
- 20 个面部动作单元（AU）原始强度，例如眉部、眼周、嘴部相关动作；
- 头部姿态：抬头/低头、左右转头、歪头的 Pitch、Yaw、Roll；
- 左右眨眼相关输出。

默认不保存身份向量，也不自动计算平均值、疲劳分数、MAD、聚类或疲劳等级。界面中的“完整 Py-Feat”会额外保存大量面部关键点、网格和其他高维数据，Excel 会明显变大；没有明确需要时，请保持默认的“精简指标”。

## 使用前只需准备两件事

1. 把要分析的视频放入一个总文件夹。一个视频只应有一名主要受试者；如果偶尔有多人入镜，程序保留面积最大且较稳定的人脸。
2. 视频名按 `受试者编号-时段-片段号` 命名，例如 `27-1-4.mp4`。其中片段号是 1 到 6；即使某位受试者缺少部分片段，也可以正常分析已有视频。

不要把“结果文件夹”放在原始视频文件夹里面；请在别处新建一个空文件夹保存结果。

## 第一次使用：安装环境

1. 从 GitHub 下载并解压**整个**项目文件夹，不要只复制其中一个 EXE。双击 `启动安装与分析助手.bat`。它会自动查找 Conda 并打开安装助手；若无法打开，会弹出清晰的错误提示并生成 `setup_launcher_error.log`，可将该文件发给维护者排查。
2. 看“下一步怎么做”这一栏，按它的提示操作：
   - 如果提示“未安装 Conda”，点击“没有 Conda？打开安装说明”。请只下载 **Miniconda（Windows x86_64，64 位）**；不要选择 Kilo，也不需要安装体积更大的 Anaconda Distribution。安装时选择 **Just Me**，保持默认路径即可，结束后重新双击本工具。
   - 如果提示“创建／修复 GPU 环境”，点击该按钮，再在确认框中点“是”。
   - 如果显示“已全部就绪”，无需安装，直接点“打开分析界面”。
3. 在“首次下载线路”中选择：网络稳定时选“官方线路”；官方 PyPI 较慢时选“国内网络优先（清华 PyPI 镜像）”。该镜像用于 Py-Feat 等常规依赖；CUDA 版 PyTorch 始终从官方专用源下载，避免混入不匹配的 GPU 版本。
4. 安装过程中，窗口会显示正在进行的步骤、已运行时间和预计剩余时间。时间是区间估计：网络、下载镜像和磁盘速度都会影响实际完成时间。不要在此期间关闭窗口或断开网络。

首次安装会下载 PyTorch、Py-Feat 等组件，约需要 7 GB 磁盘空间。小型 EXE 本身只负责显示界面和启动安装，不包含这套环境；因此下载包很小，但首次安装仍需要网络。即使没有 NVIDIA 显卡，工具仍可运行：在分析界面选择 CPU 即可，但会慢很多。

## 每次分析：只需四步

1. 双击 `启动微表情调试界面.bat`；也可以从安装助手点击“打开分析界面”。
2. 在“原始视频文件夹”选择放视频的总文件夹。
3. 在“中间暂存／结果文件夹”选择一个用于保存结果的空文件夹或以前用过的结果文件夹。
4. 保持默认设置：GPU（如可用）、12 fps、每批图片数 8、精简指标。先点 **1. 预检（不分析）**。

预检只检查视频能否打开、命名是否正确、帧率和 GPU 是否可用，不会开始分析。预检没有问题后，点 **2. 开始批量分析**。

对 24 fps 视频，12 fps 表示按时间均匀保留约每隔 2 个原始帧的一张画面；它不是把某一秒的前 12 张画面都堆在一起。

## 分析中断怎么办？

可以点击“停止当前任务”。已完成的部分会保存为检查点；下次选择**同一个**原始视频文件夹和**同一个**结果文件夹，再次点“开始批量分析”，程序会跳过已经完成的内容并继续。

如果视频分批处理，例如今天分析一部分、明天继续，请始终使用同一个结果文件夹。全部批次完成后，点击 **3. 汇总已有暂存结果**：它只读取已完成的 Excel，不会重新分析视频。

## 在哪里看结果？

结果文件夹中主要有三类内容：

- 每个视频一个独立文件夹，其中 `frame_features.xlsx` 是该视频的逐帧原始数据；
- 每位受试者/时段一个 `session_timeline_raw.xlsx`，按片段号把已有视频写进统一时间轴；缺失片段会保留空档，不会伪造数据；
- `all_analysis_raw.xlsx`：本次结果文件夹内所有已完成片段的汇总原始表。

每段视频还可能有 `face_detection_quality.png`。它只用于检查人脸是否稳定地被识别，例如是否有遮挡、转头或离镜；它不是情绪分数、微表情强度或疲劳指标。

## 常见问题

**没有 GPU 能用吗？** 可以。在分析界面选择 CPU；只是耗时会更长。

**显存不足怎么办？** 把“每批图片数”从 8 改成 4，再重新开始。

**视频不够六段怎么办？** 可以直接分析。汇总表会标出实际存在和缺少的片段。

**想改成别的抽样率？** 在主界面修改“抽样率（fps）”。研究中建议同一批数据保持同一设置；改变 fps 后应使用新的结果文件夹，避免混在一起。

**旧脚本仍报 TorchCodec / DLL 错误怎么办？** 请从本目录的两个启动器进入，不要从旧 `V2` 脚本启动。本工具使用 OpenCV/FFmpeg 解码视频，并让 Py-Feat 接收图片输入，以避开 Windows 下旧环境常见的 TorchCodec DLL 冲突。

## 隐私提示

原始视频和生成的 Excel 结果只保存在你选择的本地文件夹。上传 GitHub 的源码仓库不包含视频、受试者图像、结果表、检查点或本机日志。
